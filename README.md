# STUDYVERSE — Premium Futuristic Educational Platform
> **CBSE Class 10 Learning Platform** • *Learn Smarter. Achieve More.*

Built with high-performance vanilla HTML5, CSS3, and modern JavaScript. Specifically optimized for 4GB RAM & dual-core systems (zero npm bloat, zero heavy WebGL/Three.js).

---

## ⚡ How to Open in VS Code

1. In VS Code, go to **File > Open Folder...** (`Ctrl + K, Ctrl + O`).
2. Select `D:\studyverse`.
3. Open `index.html`.

### 🌐 Previewing the Site

- **Option A (Live Server - Recommended)**:
  - If you have the **Live Server** extension installed, right-click `index.html` and choose **"Open with Live Server"** (or click **Go Live** at the bottom-right status bar).
  - Your browser will open at `http://127.0.0.1:5500/index.html`.
- **Option B (Direct Open)**:
  - Right-click `index.html` > **Reveal in File Explorer** > double-click `index.html` to open directly in Chrome/Edge.
